Documentation Client

Site Web Portfolio - Gestion de CV étudiants

1. Fonctionnalités principales

Front-Office (partie publique)

  • Accueil : page de présentation du site
  • Recherche de CV : affichage des portfolios étudiants sous forme de cartes
  • Détail d'un portfolio : image, description, nom de l'étudiant et lien LinkedIn
  • Formulaire de contact : envoi d'un message (prénom, nom, message)
  • Connexion : login pour étudiants et administrateurs
  • Profil étudiant : modification des informations personnelles
  • Mentions légales & CGV et Plan du site

Back-Office (administration)

  • Dashboard : nombre de portfolios et d'utilisateurs
  • Gestion des Portfolios : ajouter, modifier, supprimer (CRUD)
  • Gestion de la FAQ : ajouter, modifier, supprimer
  • Gestion des Utilisateurs : ajouter et supprimer des comptes
  • Envoi de mails : envoyer un message à tous les utilisateurs

2. Technologies utilisées

Langage serveurPHP (POO, Namespaces, Autoloader)
Base de donnéesPostgreSQL
Accès BDDPDO (requêtes préparées, FETCH_CLASS, transactions)
ArchitectureMVC (Modèle - Vue - Contrôleur)
Framework CSSW3.CSS
SécuritéSessions PHP, tokens CSRF, password_hash, htmlspecialchars
URLRéécriture via .htaccess (mod_rewrite)
CookiesBannière de consentement (RGPD)
Hébergementpedago.univ-avignon.fr
